## 📌 Judul Projek Akhir
**Sistem Otomasi Pakan dan Monitoring Lingkungan Kandang Pintar dengan Integrasi Blynk dan Telegram.**

## 📝 Deskripsi
Projek ini bertujuan untuk membantu pemilik hewan peliharaan dalam memantau kondisi kandang (suhu) serta level air minum secara real-time. Sistem ini memiliki fitur utama:
1. **Pemberian Pakan Otomatis:** Berdasarkan jadwal (NTP Server) atau kontrol manual melalui aplikasi Blynk.
2. **Monitoring Lingkungan:** Sensor DHT untuk memantau suhu kandang.
3. **Notifikasi Darurat:** Menggunakan Bot Telegram untuk mengirimkan alert jika persediaan air minum habis.

## 🔌 Komponen yang Digunakan
* **Mikrokontroller:** ESP32
* **Sensor Suhu:** DHT11
* **Sensor Air:** Water Level Sensor
* **Aktuator Pakan:** Motor Servo
* **Platform IoT:** Blynk dan Telegram
